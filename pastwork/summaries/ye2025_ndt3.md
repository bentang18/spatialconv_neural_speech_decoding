# Ye et al. 2025 - NDT3: A Generalist Intracortical Motor Decoder

## Citation
Ye, J., Collinger, J.L., Bhagat, N., Bhatt, P., Schwartz, A.B., Bhattacharyya, S., Poe, G.R., Bhatt, P., Ganguly, K., Seo, D., Shenoy, K.V., & Gallego, J.A. (2025). A Generalist Intracortical Motor Decoder. arXiv, Feb 2025.

## Setup
- **Recording modalities**: Utah microelectrode arrays + Neuropixels. Features: spike counts and spike-band power
- **Species**: Monkeys and humans, 30+ subjects total
- **Data scale**: ~2000 hours of neural data, ~1 billion neural tokens
- **Tasks**: Motor tasks -- reaching, grasping, cursor control, handwriting, speech (attempted)
- **Compute**: 20,000 A100-hours for the 350M/2khr configuration (400 epochs)

## Architecture
- **Type**: Autoregressive causal Transformer (GPT-style, left-to-right generation)
- **Scale**: Two sizes tested -- 45M and 350M parameters
- **Input tokenization**: Neural data patched spatially (32 channels per patch) and temporally (20ms bins). Creates a flat token sequence
- **Embeddings**: RoPE for temporal position + learned modality embeddings (distinguish neural channels, kinematic dimensions, etc.)
- **Read-in/read-out**: Linear layers per modality (neural input, kinematic output). NOT per-subject -- all subjects share the same projection layers
- **Joint objective**: Autoregressive next-token prediction combining MSE for kinematics and CE for discretized spike counts. Model jointly predicts behavior and neural activity at each timestep
- **Covariate dropout**: At each training step, randomly drop entire input modalities with probability M ~ U[0,1]. Prevents the model from relying on teacher-forcing shortcut (copying previous kinematic token instead of decoding from neural activity). Critical for preventing trivial solutions in autoregressive models
- **NO per-subject layers**: All subjects share identical architecture. Cross-subject transfer relies entirely on the shared representation learning to absorb inter-subject variability

## SSL/Pretraining
- **NOT self-supervised**: Uses supervised autoregressive training on paired neural + behavioral data throughout. The pretraining corpus includes behavioral labels (kinematics) for all sessions
- **Training**: 400 epochs, AdamW optimizer
- **Data scaling**: Tested 50h, 200h, 500h, 2000h pretraining corpora. Benefits require joint data + model scaling (2000h helps only at 350M, not 45M)

## Cross-Patient Handling
- **No per-patient parameters**: This is the FUNDAMENTAL LIMITATION. All subjects share the same linear read-in/read-out per modality (not per subject)
- **Cross-subject R^2 ~0.5 vs cross-session ~0.7**: Substantial degradation when evaluating on held-out subjects. The gap is primarily due to sensor variability (electrode placement, impedance, tissue interface differences)
- **Channel shuffle experiment**: Randomly permuting channel order within a single session reduces cross-session performance to cross-subject level. This proves that sensor identity (which channel is where) is the primary barrier, not neural variability
- **Output stereotypy**: The autoregressive decoder fails to extrapolate to held-out reach angles not seen during training. It generates stereotyped output trajectories. A simple linear PCA-LDA decoder generalizes better to novel angles. This is a fundamental failure mode of AR models trained on limited behavioral diversity
- **Authors explicitly identify per-patient layers as needed future work**

## I/O Features
- **Input**: Spike counts + spike-band power from Utah arrays / Neuropixels, 20ms temporal bins, 32-channel spatial patches
- **Output**: Continuous kinematics (cursor velocity, joint angles) via MSE + discretized spike counts via CE
- **Autoregressive**: Each timestep conditions on all previous timesteps. Teacher-forced during training with covariate dropout to prevent shortcut learning

## Key Results
| Configuration | Cross-Session R^2 | Cross-Subject R^2 |
|---|---|---|
| 350M, 2khr | ~0.70 | ~0.50 |
| 45M, 2khr | ~0.65 | ~0.45 |
| 350M, 200h | ~0.60 | ~0.40 |

Key findings:
- **350M + 2khr is statistically best overall**, but the scaling benefit is modest. Joint data + model scaling required (2khr only helps at 350M)
- **Benefits vanish at ~1.5h downstream data**: With sufficient fine-tuning data from the target subject, pretraining provides no advantage. The foundation model primarily helps in low-data regimes
- **Handwriting (CTC task) NOT helped by pretraining**: The most complex downstream task shows no benefit, suggesting the pretrained representations don't capture fine motor control well
- **Spikes != HGA**: All data is from intracortical spike recordings. Not applicable to field potential modalities (ECoG, sEEG HGA) -- different biophysics, cannot pool

## v12 Comparison

**THE key negative result paper for cross-subject neural decoding.** NDT3 is the largest-scale attempt at a generalist neural decoder (2000h, 350M params, 30+ subjects) and its cross-subject transfer failures are deeply informative for v12's design.

**Why NDT3 fails where v12 should succeed:**
1. **No per-patient layers**: NDT3's most critical design gap. The channel shuffle experiment proves sensor variability is the bottleneck. v12's 134-param per-patient diagonal normalization (scale + bias) directly addresses this. BIT (with per-subject read-in/out) succeeds at cross-subject transfer; NDT3 (without) fails. The evidence is now overwhelming that per-patient layers are necessary
2. **No spatial prior**: NDT3 treats channels as an unordered set (channel shuffle destroys performance). v12's MNI coordinates + atlas-grounded VE cross-attention explicitly encode spatial relationships, making the model invariant to electrode permutation by design
3. **Autoregressive output stereotypy**: NDT3's AR decoder generates stereotyped outputs when extrapolating to unseen reach angles. v12 mitigates this by constraining beam search to the 52 valid CVC/VCV tokens in the vocabulary -- the model cannot hallucinate invalid sequences. Additionally, v12's output space (9 phonemes x 3 positions = 52 tokens) is far more constrained than NDT3's continuous kinematics

**What to import:**
- **Covariate dropout** (M ~ U[0,1]): Drop entire input modalities/channels randomly during training. Prevents teacher-forcing shortcuts in AR decoders. Directly applicable to v12's AR decoder training -- randomly dropping electrode subsets forces the model to decode from partial observations
- **Channel shuffle as diagnostic**: Use channel permutation as a sanity check for v12. If v12's performance is invariant to channel shuffle (it should be, given VE cross-attention with coordinates), this validates that spatial information is being used correctly
- **Scaling law insight**: Benefits of pretraining vanish with ~1.5h downstream fine-tuning data. v12 has ~1 min/patient epoched (well below this threshold), confirming that SSL pretraining should help significantly

**What to avoid:**
- **No per-patient params**: The clearest lesson. NDT3 + BIT together prove that per-patient layers are non-negotiable for cross-subject transfer in neural decoding
- **Pure autoregressive on continuous outputs**: AR is dangerous for extrapolation. v12's constrained token vocabulary avoids this, but the caution stands
- **Massive scale without addressing sensor variability**: 2000h and 350M params cannot compensate for the lack of per-patient normalization. Architecture > scale for this problem
