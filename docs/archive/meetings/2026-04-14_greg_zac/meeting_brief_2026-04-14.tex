\section{Current Thesis}

The bottleneck is \textbf{not} generic sequence modeling. It is \textbf{cross-patient spatial comparability} under variable array placement and partial cortical coverage. The current claim is:

\begin{itemize}
\item \textbf{Objective}: learn a patient-invariant latent of \textbf{cortical articulatory state}, not just a model that fine-tunes quickly.
\item \textbf{v14 decomposition}: per-patient atlas-guided calibration, then shared spatiotemporal dynamics, then phoneme decoding.
\item The shared object is an atlas-grounded regional token space, not raw channels.
\end{itemize}

\section{What Changed Since Friday}

The Friday PDF is now stale in five important ways:

\begin{itemize}
\item \textbf{No more spherical nodes / Wendland kernel as the default.} We now use \textbf{Brainnetome volumetric parcellation membership}.
\item \textbf{No more single 16-node interface by default.} The active interface is \textbf{21 atlas/subparcel tokens}, with selective splitting of elongated motor/sensory parcels.
\item \textbf{Stronger temporal front-end.} The old minimal Conv1d stem is replaced by a small \textbf{BaRISTA-style shared temporal tokenizer} over overlapping per-channel patches.
\item \textbf{Spatial mapping is now atlas-grounded local summarization, not multi-view attention.} The default is a small \textbf{shared within-parcel Perceiver-style summarizer} that emits atlas/subparcel tokens; mean+gradient pooling is now the linear ablation.
\item \textbf{Decoder is now a joint readout.} Three learned queries cross-attend to \emph{all} token-time features with autoregressive conditioning, rather than relying on rigid temporal pooling.
\end{itemize}

\section{Why This Direction Is Defensible}

\begin{itemize}
\item \textbf{Best literature support}: BaRISTA is the strongest paper for our spatial question. Its central result is that \textbf{parcel-level encoding beats channel-level encoding} and also beats PopT-style channel-based baselines on key tasks.
\item \textbf{Independent convergence}: MIBRAIN / Neuro-MoBRE also converge on \textbf{atlas or region-level common spaces} for cross-patient intracranial decoding.
\item \textbf{Scale alone is not enough}: huge generic pretraining corpora still do \emph{not} remove the need for explicit spatial identity. SWEC / MVPFormer are strategically important, but they do not beat more spatially grounded models on every Brain Treebank task.
\item \textbf{Precision sharpens the architecture}: ultra-dense $\mu$ECoG shows richer local structure exists inside parcels, so the right hierarchy is now explicit in the default model: \texttt{local within-parcel Perceiver summarizer} $\rightarrow$ \texttt{atlas/subparcel tokens} $\rightarrow$ \texttt{shared dynamics}. The remaining question is how small and shared that local summarizer should be.
\end{itemize}
