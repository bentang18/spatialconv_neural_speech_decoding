0. Thesis & scope

Thesis. An iEEG foundation model with anatomy-tagged factorized Perceiver IO and soft parcel-routing cross-attention (log(support+ε) over BrainTreebank–Desikan-Killiany one-hot), pretrained with a factorized t×f Stage A token-mask phase + an electrode-mask Stage B phase + a multi-teacher Phase-3 distillation (Whisper-L8 + DINOv3), beats PopT cross-subject by ≥0.05 AUROC at ≤30M params on the 9-subject BrainTreebank cohort.

Model sized=256, 8 heads, ~13M params (5–15M target; ≤30M cap).

1. Preprocessing pipeline preprocessing

Raw iEEG voltage → model input tensor (C electrodes, F=30 freq-bins, T time-bins). BrainTreebank-specific (2048 Hz native).

1HPF 0.5 Hz
Butterworth filtfilt high-pass — removes DC drift before robust-z statistics are estimated.
▼
2Comb filter @ 60 Hz
scipy.signal.iircomb(w0=60, Q=30, ftype='notch', fs=fs) — single true comb filter; rejects all 17 line-noise harmonics (60–1020 Hz) in one pass.
▼
3MNE-LOF channel-quality flag
mne.preprocessing.find_bad_channels_lof, threshold 1.5, n_neighbors 20, per session. Emits per-session bad-channel mask.
▼
4shaftCAR over good channels
Common-average re-reference within each shaft, computed over non-flagged channels only. Kills within-shaft common-mode noise; leaves spatial structure for the model's learned inverse.
▼
5Drop flagged-bad channels
Bad channels removed from the token sequence before slicing — clean handoff (C_good × T).
▼
6Slice trial window
Onset-anchored [0, 1] s (A.0); avoids pre-stimulus contamination from previous-trial residue.
▼
7STFT
Magnitude STFT — Neuroprobe swept-optimal window/hop parameters. The STFT is the patch embedding: each STFT cell = one patch.
▼
8Triangular ⅓-octave filterbank
30 bins, mel-style overlapping edges, uniform log spacing. Centers f_k = 2^(k/3) Hz, k=0…29 (1 Hz–813 Hz). See §2.
▼
9Log-power compression
log(filterbank_energy + ε), ε ≈ 1e-6 (AST log-mel convention). Phase discarded here — input is log-magnitude only.
▼
10Nv14 robust-z normalization
Per (electrode, freq-bin, session): (x − median) / (1.4826 · MAD), full-session pooled over time only. Robust to sEEG artifact spikes; per-session scope makes a SWEC-pretrained model transfer to BT (different amplifiers/gains).

2. Filterbank — 30-bin log ⅓-octave preprocessing

Centers f_k = 2^(k/3) Hz. Triangular filter for bin k spans [f_{k-1}, f_{k+1}], peak at f_k, 50% neighbor overlap. Upper edge of bin 29 = 210 = 1024 Hz = Nyquist.

3. Architecture — 7 stages architecture

Factorized throughout: token blocks do t×f, latent stack does t×parcel. Latents keep a time axis — (320, T, d).

Stage-by-stage specification

❶Input embedding(C,F,T) → (C,F,T,d)
  • A1 linear embed — Linear(1 → d) applied per (t,f) cell, shared across all cells. This is the patch-embedding projection; the patch is one STFT cell (AST Conv2d-patchify at patch size 1×1).
  • Categorical freq embedding — 30 independent learnable d-vectors, added per freq-bin. Flat / non-separable (NOT factored into band⊗position) so freq-embedding clustering can recover brain bands without supervision.
  • No time PE at input — time is encoded relatively via RoPE inside ❷.
❷Token block × N=4 — per-electrode, factorized t × f(C,F,T,d) → (C,F,T,d)
  • Each block (TimeSformer-divided / axial attention): temporal SA → residual, then freq SA → residual, then MLP → residual.
  • Temporal SA applies RoPE (θ=10000) to Q/K — relative, translation-equivariant time.
  • Freq SA attends across the 30 categorical bins, time fixed.
  • Hard −∞ cross-electrode mask — no electrode↔electrode mixing here; the activation cascade across regions is modeled only in the latent stack.
  • Block internals: pre-norm, LayerNorm, GeLU, MLP 4×, 8 heads (32 dim/head).
N=4 default; sweep {2,4,6}.
❺Parcel-routed cross-attention — 2 layers @ {0,3}(C,F,T,d) → (320,T,d)
  • 320 free latents — nn.Parameter(320,d), truncated-normal init std ≈ 0.02 (Perceiver-IO standard). 320 = K=80 DK parcels × M=4 slots. Parcel identity is carried by the cross-attn bias, not the latent vector.
  • Pools (electrode, freq) → parcels strict 1:1 per time-step: latent-time-t attends only to (C,F) tokens at time t. T_latent = T; no resampling in the encoder.
  • Anatomy bias on the QK score: log(support[e,p] + ε), ε=1e-2 (tunable anatomy-prior strength), support = BT-DK one-hot. Graphormer-style additive bias.
  • 2 cross-attn layers inserted at positions {0,3} of the L=6 latent stack — multi-pass routing for dense parcels (STG/IFG).
  • Latents keep a time axis — required for non-degenerate Phase-3 cross-modal alignment and to model cross-parcel temporal dynamics.
❻Latent stack × L=6 — factorized time × parcel(320,T,d) → (320,T,d)
  • Each layer: time SA (RoPE) → residual, then parcel SA → residual, then MLP → residual.
  • Time SA models within-parcel temporal evolution; parcel SA + the time interleave model cross-parcel temporal dynamics (auditory → STG → motor cascade).
  • Native rate kept (~STFT rate, ~13 Hz) — finer than the 10 Hz teacher-target rate.
L=6 default; factorization order time-first (sweepable).
❼PMA readout — Set Transformer (Lee 2019)(320,T,d) → (k,d) → out
  • k learnable seed queries cross-attend the latent set; standard readout primitive.
  • Downstream: k=1 (or k=n_tasks for multi-task ≥4) → Linear(d → n_classes) minimal head (keeps frozen-linear-probe comparison clean).
  • Phase-3: k=50 queries → 50 buckets @ 10 Hz → Smooth-L1 vs fused teacher. The PMA-K=50 adapter is the rate-bridge (collapses parcels, buckets time to syllable rate).

Spatial information — 2 mechanisms, disjoint roles

6. Objectives & losses loss

Phase 1 — L_recon Level B (token-mask JEPA)

L_recon_B = MSE( predictor(student tokens, mask), StopGrad( EMA-teacher latent, layer-averaged ) )
  • 80% inverse-block mask on the per-electrode (t,f) grid.
  • data2vec-2.0 target construction: average top-K teacher FFN block outputs, instance-norm.
  • UFO dual-scale: frame loss + utterance loss, λ=1.
  • EMA teacher prevents collapse; no KoLeo term (pruned 2026-05-12).

Phase 2 — L_recon Level A (electrode-mask JEPA)

L_recon_A = MSE( student latents, StopGrad( EMA-teacher Stage-B latents, full electrode set ) )
  • 30% random whole-electrode mask applied to Stage-A features before cross-attn.
  • Trains cross-attn + latent stack to be robust to electrode dropout — directly relevant for cross-subject transfer.

Phase 3 — cross-modal distillation

L_distill = Smooth-L1( v14 adapter output[50 buckets], fused-teacher target[50 buckets] )
  • Smooth-L1 (data2vec-2.0 §3.4, outlier-robust at β=0.5–2.0); cosine = P1 sister.
  • K=50 bucketed-pooled at 10 Hz — syllable rate, where iEEG↔Whisper-L8 alignment exists (Goldstein 2025). Per-frame 50 Hz rejected; utterance-pooling rejected.
  • Fused teacher = gating-MLP-weighted Whisper-L8 + DINOv3 (Stage 3a).
  • Distill into the iEEG latent space — the iEEG encoder is the bottleneck and the downstream-probed model; teachers are bridge supervision.
